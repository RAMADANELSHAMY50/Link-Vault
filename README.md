
# Link Vault

## Project Overview
Link Vault is a React application built with Vite.

## Technologies & Libraries

- React: Building the user interface.
- React Router DOM: Managing navigation between application pages.
- Axios: Handling HTTP requests to the backend API.
- Zustand: Managing global application state and user authentication.
- Formik: Managing forms such as login and registration.
- Yup: Validating user input in forms.
- Tailwind CSS: Styling the application using centralized design tokens.
- React Icons: Providing icons for navigation and interface components.

## Installation

npm install

## Run Development Server

npm run dev
